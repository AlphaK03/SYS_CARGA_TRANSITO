# Capturas de la guía de registro

Capturas reales de Microsoft Entra ID en Edge, tomadas el 4 de octubre de 2026.
Los recuadros y números son anotaciones de orientación sobre la interfaz;
no se alteraron los valores ni los estados de los controles.

Se creó el registro `Gestor de reportes - Ejemplo temporal`:

- Client ID: `5105bb0e-cd85-4627-a852-fb26c4bc6f9d`.
- Object ID del registro temporal: `72ade77c-774c-47b7-8d72-6d1944aebb3e`.
- Plataforma: cliente público de escritorio, con retorno `http://localhost`.
- Permisos delegados: Microsoft Graph `User.Read`, `Mail.Send`; SharePoint `AllSites.Read`.

El registro temporal fue eliminado y el portal confirmó su eliminación.
La lista activa volvió a mostrar las tres aplicaciones previas, incluida
CHC Reportes Astra. No se crearon secretos ni se concedió consentimiento
administrativo al ejemplo. No se enviaron correos.

Las capturas 06 y 07 muestran permisos ya guardados, por lo que el botón
«Agregar permisos» está inactivo. En la captura 08, la cuenta usada no tiene
habilitada la concesión de consentimiento administrativo. La guía explica
ambos estados y los pasos para una cuenta de TI autorizada.

La captura 02 se repitió en un formulario sin guardar para mejorar el encuadre;
ese formulario se descartó sin crear una segunda aplicación.

Los identificadores de las imágenes son ejemplos; no deben copiarse para
configurar el programa de otra organización.
